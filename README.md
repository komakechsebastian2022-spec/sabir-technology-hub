# Sabir Technology Hub Website

## Overview
A professional website for Sabir Technology Hub - a technology and digital services center based in Kitgum, Northern Uganda. The website showcases services including computer repair, printing, typing, scanning, internet services, and digital marketing solutions.

## Features

### 1. **Responsive Design**
   - Mobile-first approach
   - Fully responsive on all devices
   - Optimized for tablets, phones, and desktop screens

### 2. **Sections**
   - **Hero Section**: Eye-catching banner with call-to-action buttons
   - **About Section**: Information about the business and key services
   - **Services Section**: Detailed showcase of all services offered
   - **Why Us Section**: Key differentiators and advantages
   - **Contact Section**: Contact information and inquiry form
   - **Footer**: Navigation links and social media connections

### 3. **Interactive Features**
   - Mobile navigation menu
   - Smooth scrolling
   - Form submission via WhatsApp
   - Floating WhatsApp widget
   - Hover effects and animations

### 4. **Services Offered**
   - 💻 Computer Repair
   - 🖨️ Printing Services
   - ⌨️ Typing Services
   - 📑 Scanning
   - 🌐 Internet Services
   - 📱 Digital Services

## Technical Stack
- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables and Grid/Flexbox
- **JavaScript**: Vanilla JS for interactivity
- **No Dependencies**: Pure HTML, CSS, and JavaScript

## Installation & Setup

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/komakechsebastian2022-spec/sabir-technology-hub.git
   cd sabir-technology-hub
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   
   # Using Node.js (with http-server)
   npx http-server
   ```

3. Visit `http://localhost:8000` in your browser

### Deployment Options

#### Option 1: GitHub Pages (Free)
1. Push to GitHub repository
2. Go to Settings → Pages
3. Select main branch as source
4. Your site will be live at `https://komakechsebastian2022-spec.github.io/sabir-technology-hub`

#### Option 2: Netlify (Free)
1. Push to GitHub
2. Visit [netlify.com](https://www.netlify.com)
3. Connect your GitHub account
4. Select this repository
5. Deploy automatically on every push

#### Option 3: Custom Domain
1. Purchase a domain (e.g., www.sabirtechnologyhub.com)
2. Use any hosting provider (Netlify, Vercel, GitHub Pages with custom domain)
3. Update DNS settings to point to your hosting provider

## Customization

### Update Business Information
Edit `index.html`:
- Phone number: Replace `+256774830802` with your number
- Email: Replace `info@sabirtechnologyhub.com` with your email
- Location: Update Kitgum address as needed
- Opening hours: Modify business hours section

### Add Logo
1. Replace `images/logo.png` with your business logo
2. Recommended size: 60x60 pixels (will be responsive)

### Customize Colors
Edit `style.css` variables:
```css
:root {
    --primary-color: #2563eb;        /* Change primary blue */
    --secondary-color: #f97316;      /* Change secondary color */
    --text-dark: #1f2937;            /* Change text color */
    /* ... more colors */
}
```

### Update Social Media Links
Edit footer and contact form:
- Facebook, TikTok, WhatsApp links in footer
- Update WhatsApp number throughout the site
